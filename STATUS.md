# STATUS

**Project:** Free Flea-Market Booth Pack
**Owner:** Asdale Dynamics, LLC
**Status:** Complete and verified — builds clean, 35/35 tests pass.

## What was built

A free, unbranded, local-first printable pack for running a tidy flea-market
booth (the vendor/market kind — deliberately distinct from a home
garage-sale kit). Eight HTML/CSS source sheets build to US-Letter PDFs with
one script.

| Sheet | Prints | Purpose |
|---|---|---|
| `blanket-layout` | 1 page | Booth layout map: blanket, till, item zones, aisle edge |
| `price-signs` | 2 pages | $1/$2/$5/$10 table signs + fill-a-bag / make-an-offer / cash-only banners |
| `price-stickers` | 3 pages | Round tag-size price stickers (50¢–$3 + blanks) and cut-apart tag strips |
| `cash-tally` | 1 page | Per-sale tally log with cash/card columns and end-of-day profit count |
| `change-card` | 1 page | Float planner, denomination quick math, till scratch space |
| `sold-tickets` | 2 pages | Twin sold/held ticket stubs with tear lines and pickup-promise halves |
| `rain-plan` | 1 page | Rain-ready packing list, booth moves when it pours, go/no-go decision |
| `load-sheet` | 2 pages | Load-in/load-out box tracker, booth kit checklist, day timeline |

Also included:

- `build.py` — single build script (WeasyPrint, fully offline). Builds all
  sheets, single sheets, or cleans builds. Auto-discovers new sheets dropped
  into `sheets/`.
- `sheets/shared.css` — one shared print stylesheet (Letter size, 0.5in
  margins, big readable type, no web fonts, offline-safe).
- `setup/` — a setup article per sheet (plain-English: what it is, how and
  when to use it, what it pairs with).
- `README.md`, `LICENSE` (MIT, Copyright (c) 2026 Asdale Dynamics, LLC),
  `requirements.txt`, `.gitignore`, `tests/test_build.py`.

## Layout of the folder

```
build.py            build script (python3 build.py [--clean] [name...])
sheets/             HTML/CSS sources (shared.css + 8 sheets)
printables/         generated PDFs (git-ignored build artifacts)
setup/              one setup article per sheet
tests/test_build.py 35 pytest checks over the built PDFs
```

## How to run it

```sh
pip install -r requirements.txt   # weasyprint, pypdf, pytest
python3 build.py                  # build all PDFs into printables/
python3 build.py cash-tally       # rebuild one sheet
python3 -m pytest tests -q        # verify every sheet builds a valid PDF
```

No accounts, no network at build time, no secrets. Sources use system fonts
only, so it works fully offline.

## Verification results

- `python3 build.py --clean` — all 8 sheets build with no warnings or errors.
- `python3 -m pytest tests -q` — **35 passed**.
- Tests verify, for every sheet: file exists, valid `%PDF-` header,
  non-trivial size, ≥1 page, ≥100 chars of extractable text per sheet, US
  Letter mediabox, and **unbranded output** (no "Asdale"/"Dylan" anywhere in
  the PDFs — branding appears only in README/LICENSE).
- Rendered every PDF page to PNG and visually reviewed page flow, sign
  sizes, sticker grids, log tables, and checklists. Fixed one layout bug
  found this way: `sold-tickets` originally overflowed its fixed-height stub
  grid; rewritten to flexible stubs (now 6 stubs per page, 2 pages total).
- `printables/` contains the 8 generated PDFs (regenerated by build/tests).

## Known gaps

- PDFs are generated, not hand-crafted to exact die-line specs; the round
  stickers are print-and-cut (fine at tag size), not a purchasable label
  template. If someone wants an Avery-compatible layout later, it is one
  more sheet away.
- Paper sizes: `@page` is fixed at US Letter. A4 users get correct margins
  (geometry triples in the tests allow ±3 pt), but a dedicated A4 variant
  sheet is not built.
- No dark-mode/paper-choice alternates (e.g., kraft-paper-friendly ink-heavy
  signs) — the current sheets are deliberately ink-frugal.
- Setup articles are markdown, readable anywhere, but there is no built HTML
  "magazine" page tying them together.
- Sheets are English-only; translations would need per-language HTML copies.
